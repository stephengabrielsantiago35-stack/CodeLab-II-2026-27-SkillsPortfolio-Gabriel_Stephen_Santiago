THE LAST 10 QUESTIONS
=====================

A horror-themed maths quiz built with Python and Tkinter.
Ten addition/subtraction questions stand between you and the door.

RUNNING THE GAME
----------------
    python The_Last_10_Questions.py

Requires Python 3.8+ with Tkinter (included with standard Python).
Optional: Pillow (pip install Pillow) for the Horror UI pack artwork
and PNG backgrounds - without it the game falls back to procedurally
drawn canvas art and still runs normally.
Optional: pygame for music/sound. If neither pygame nor the Windows
sound APIs are available the game runs silently.

FONTS
-----
The game uses Creepster (bundled in assets/fonts/) for all UI text -
titles, buttons, labels, feedback and endings - giving it the horror
look. The maths itself (equations and the answer box) stays in
Consolas so the numbers remain easy to read. The bundled font is
loaded privately for the running game only; nothing is installed
system-wide. If the font file is missing the game falls back to
Impact / Segoe UI automatically.

HOW TO PLAY
-----------
1. Press PLAY on the title screen.
2. Pick a difficulty:
       EASY      numbers 1 - 9
       MODERATE  numbers 10 - 99
       ADVANCED  numbers 1000 - 9999
3. Answer 10 questions. Each question gives you 2 attempts:
       correct on 1st attempt .... 10 points
       correct on 2nd attempt ....  5 points
       still wrong ................  0 points (answer revealed)
4. Survive to the results screen. Rank is based on your score:
       90-100  A+   80-89  A   70-79  B   50-69  C   0-49  F

Typing a non-number counts as a wrong attempt - the entity is watching.

CONTROLS
--------
Mouse   - all buttons and the answer box
Enter   - submit your answer
MUSIC   - toggle the soundtrack (menu / results screens)
ESC     - quit

CONTENTS
--------
The_Last_10_Questions.py   the entire game (single file)
assets/music/              ambient soundtrack (generated WAV)
assets/sounds/             sound effects (generated WAVs)
assets/ui/                 Horror UI pack artwork (panels, buttons, icons)
assets/generate_sounds.py  regenerates all audio if needed

PROJECT STRUCTURE (design-doc functions)
----------------------------------------
Required functions are all present as module-level functions bound
onto the Last10Questions class:
    displayMenu()      randomInt(minimum, maximum)
    decideOperation()  displayProblem()
    isCorrect(user_answer)   displayResults()
Extras: startGame, nextQuestion, submitAnswer, updateStatus,
        toggleMusic, showFeedback.
