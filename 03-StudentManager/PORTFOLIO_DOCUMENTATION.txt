THE ACADEMY LEDGER — Portfolio Documentation (200–300 words)

The Academy Ledger is a fantasy academy student records management application built with Python and Tkinter. Its purpose is to give an academy archivist a polished, enchanted-archive interface for managing apprentice records while preserving the original Student Manager functionality. The system loads records from resources/studentMarks.txt, displays them in a clear table with calculated totals, and supports the required operations: viewing all records, searching by name or code, finding the highest and lowest totals, sorting records in ascending or descending order, adding new records, deleting records with confirmation, and updating existing records. All changes are saved back to the original file format.

The application uses Python concepts including functions for each menu operation, lists and dictionaries for in-memory record management, loops and conditionals for processing and validation, exception handling for robust file/input errors, and modular GUI-building helpers. Libraries used include tkinter, tkinter.ttk, tkinter.messagebox, csv, and os, with optional Pillow support for decorative images. File handling is implemented through relative paths based on the script directory; records are loaded at startup, validated, and saved by rewriting studentMarks.txt with the original count header and CSV row structure.

A key challenge was preserving data integrity while adding CRUD features. I solved this by centralising validation in normalise_student() and validate_student_input() and rolling back in-memory changes if a save fails. Another challenge was making the interface visually distinctive but usable; guided by the Anthropic Frontend Design skill (accessed and read from the public GitHub SKILL.md), I chose a midnight navy, parchment, and warm-gold palette, clear Georgia/Segoe UI typography, and a signature ledger-spine motif. I learned how thoughtful design constraints, careful validation, and reliable file handling combine to produce a functional and polished desktop application.
